# 🚀 Roadmap разработки Deprecio

Цель проекта — единая аналитическая платформа для оценки смартфонов на вторичном рынке с API и Telegram-ботом.

## Статус этапов

### 1. Основа проекта — ✅ выполнено
- [x] Зафиксирована доменная модель устройств, региональных версий, комплектаций и объявлений.
- [x] Разделены доменная логика, источники данных и пользовательские интерфейсы.
- [x] Настроены единый стиль кода, CI, pytest и локальный запуск.
- [x] Описаны конфигурация и секреты через Pydantic Settings и `.env`.

### 2. Каталог устройств — ✅ выполнено
- [x] Реализованы нормализованные идентификаторы, поиск по каталогу и локальный провайдер.
- [x] Подготовлены `catalog.json` и предсобранная `global_devices.db`.
- [x] Добавлен общий контракт провайдеров для подключения новых источников.
- [x] Расширены автоматические проверки дубликатов и качества исходных данных.

### 3. Сбор и очистка цен — ✅ выполнено
- [x] Определены модели объявлений и агрегатор рынка.
- [x] Добавлены базовые правила очистки и санитизации.
- [x] Подключены production-адаптеры источников, ограничение частоты запросов и журналирование.
- [x] Расширено исключение неликвида, дубликатов и статистических выбросов.

### 4. Аналитическое ядро — ✅ выполнено
- [x] Реализованы метрики, остаточная стоимость, параметры комплектности и расчёты прогноза.
- [x] Добавлены профили прогноза и fuzzy-поиск.
- [x] Добавлено сравнение поколений и подбор аналогов в бюджете.
- [x] Документированы ограничения точности прогноза и факторы Sweet Spot Score.

### 5. Единый API — ✅ базовая версия выполнена

- [x] Добавлены маршруты устройств и прогнозов под `/api/v1`.
- [x] Добавлены стабильная версия API, ограничения параметров и расширенная обработка ошибок.

### 6. Telegram-бот — ✅ базовая версия выполнена
- [x] Реализован запуск aiogram long polling и регистрация роутеров.

- [x] Подключены общие провайдеры и обработка ошибок.
- [ ] Добавить избранное, уведомления об изменении цены и устойчивое внешнее кэширование.

### 7. Веб-интерфейс — ✅ выполнено

## После v1.0

- Расширить каталог новыми брендами, регионами, вариантами памяти и регулярными импортами.
- Добавить ML-прогнозирование с версионированием моделей, валидацией качества и контролем дрейфа.
- Реализовать push-уведомления о снижении цены, достижении Sweet Spot и изменениях прогноза.

## Текущий приоритет

Укрепить сбор и очистку рыночных данных, расширить аналитическое ядро и стабилизировать API-контракты. Затем развивать веб- и мобильные клиенты поверх API.

## Основной стек

- Python 3.11+, Pydantic, FastAPI, aiogram;
- pytest и Ruff;
- Docker и GitHub Actions;
- SQLite для локального глобального каталога устройств.

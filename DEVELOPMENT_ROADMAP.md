# 🚀 Roadmap разработки Deprecio

**Цель:** единая аналитическая платформа для оценки смартфонов на вторичном рынке с общим API, Telegram-ботом, веб-интерфейсом и Android-приложением.

План построен по этапам, а не по календарным срокам. Каждый этап заканчивается рабочим результатом. Поэтому проект можно завершить быстрее, развивать дольше или временно менять приоритеты без переписывания дорожной карты.

## 🧭 Этапы

### 1. Основа проекта
- [ ] Зафиксировать доменную модель: устройство, региональная версия, комплектация, объявление и история цены.
- [ ] Разделить доменную логику, источники данных и пользовательские интерфейсы.
- [ ] Настроить единый стиль кода, CI и локальный запуск.
- [ ] Описать конфигурацию и работу с секретами.

**Результат:** проект устанавливается с нуля, проверки запускаются автоматически, ключевые модели документированы.

### 2. Каталог устройств
- [ ] Нормализовать идентификаторы брендов, линеек и моделей.
- [ ] Реализовать поиск по бренду, названию, линейке и региональной версии.
- [ ] Проверить дубликаты, неполные карточки и качество исходных данных.
- [ ] Сохранить возможность подключать новые провайдеры через общий интерфейс.

**Результат:** поиск возвращает корректные карточки, а новый источник подключается без изменения доменной логики.

### 3. Сбор и очистка цен
- [ ] Определить формат объявления и историю наблюдений за ценой.
- [ ] Добавить адаптеры источников, ограничение частоты запросов и журналирование.
- [ ] Исключать неликвид, повреждённые устройства, дубликаты и выбросы.
- [ ] Хранить дату, источник, регион, состояние и комплектность объявления.

**Результат:** аналитика строится на воспроизводимой очищенной выборке.

### 4. Аналитическое ядро
- [ ] Реализовать остаточную стоимость и разницу цен региональных версий.
- [ ] Учесть состояние устройства и комплектность.
- [ ] Добавить сравнение поколений и подбор аналогов в бюджете.
- [ ] Реализовать прогноз с понятными входными данными и ограничениями точности.
- [ ] Рассчитать Sweet Spot Score и объяснять факторы оценки.

**Результат:** расчёты доступны программно, проверяемы и понятны пользователю.

### 5. Единый API
- [ ] Подготовить FastAPI как общий слой для сайта, бота и приложения.
- [ ] Добавить поиск, карточку устройства, прогноз, остаточную стоимость и сравнение.
- [ ] Версионировать API и описывать схемы через OpenAPI.
- [ ] Добавить обработку ошибок, ограничения запросов и задел под авторизацию.

**Результат:** все клиенты используют один документированный API.

### 6. Telegram-бот
- [ ] Реализовать `/start`, поиск, карточку, сравнение и прогноз.
- [ ] Добавить пошаговые сценарии, клавиатуры и обработку ошибок.
- [ ] Подключить кэширование повторяющихся запросов.
- [ ] Подготовить избранное и уведомления об изменении цены.

**Результат:** основной пользовательский сценарий доступен в Telegram.

### 7. Веб-интерфейс
- [ ] Создать адаптивный поиск с фильтрами.
- [ ] Добавить карточку устройства, график цен и прогноз.
- [ ] Реализовать сравнение моделей и ссылку на результат.
- [ ] Обработать состояния загрузки, пустого результата и ошибки API.

**Результат:** сайт закрывает основной сценарий на компьютере и мобильном экране.

### 8. Android-приложение
- [ ] Выбрать React Native/Expo после стабилизации API и веб-сценариев.
- [ ] Реализовать поиск, карточку, сравнение, избранное и локальный кэш.
- [ ] Добавить push-уведомления после появления модели пользователя.
- [ ] Настроить сборку APK и тестовые публикации через GitHub Releases.

**Результат:** приложение использует тот же API и повторяет основные сценарии сайта.

### 9. Выпуск и развитие
- [ ] Контейнеризировать API и фоновые задачи.
- [ ] Настроить резервное копирование, мониторинг и журналирование.
- [ ] Проверить критические сценарии, производительность и безопасность.
- [ ] Подготовить техническую и пользовательскую документацию.
- [ ] Выпустить первую стабильную версию и вести список изменений.

**Результат:** проект можно развернуть по инструкции и поддерживать после релиза.

## 🧱 Текущий приоритет

Сначала укрепить каталог и аналитическое ядро на существующих данных, затем вынести их через API. Telegram-бот, сайт и APK подключаются к готовым контрактам API по мере готовности.

## 🛠️ Основной стек

- Python 3.11+, Pydantic и pytest.
- FastAPI как общий API.
- aiogram для Telegram-бота.
- React/Next.js и TypeScript для веб-интерфейса.
- React Native/Expo для Android.
- Docker и GitHub Actions для сборки и доставки.

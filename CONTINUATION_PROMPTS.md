2. Определи стабильный контракт для пустого результата: нулевые метрики, пустые editions и condition_medians.

4. Проверь корректность outliers_count: дефектные объявления и ценовые выбросы не должны учитываться дважды.
5. Проверь случай, когда все цены одинаковые.
6. Добавь тесты для пустого списка, списка только с дефектными объявлениями, списка только с нереалистичными ценами и смешанной выборки.

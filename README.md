## 🎯 О проекте

**Deprecio** (от фин. *depreciation* — обесценивание, амортизация) — это исследовательский и аналитический инструмент для энтузиастов мобильных технологий, который изучает динамику цен на смартфоны:
- С момента официального релиза (MSRP) до вторичного рынка.
- Анализирует разницу между **китайским (CN)** и **международным (Global)** рынками.
- Прогнозирует сроки и величину падения цен на новинки (например, свежеанонсированные флагманы).
- Вычисляет **«Sweet Spot Window»** — оптимальную точку покупки б/у и субфлагманов, когда цена вышла на стабильное плато, а железо остается максимально актуальным.

## 📊 Ключевые метрики

| Метрика | Описание |
| :--- | :--- |
| **RV% (Residual Value)** | Процент остаточной стоимости устройства от стартовой цены (MSRP). |
| **DMR (Monthly Decay)** | Скорость удешевления (% в месяц) для конкретной линейки. |
| **Import Premium Index** | Наценка серовозов/перекупов в первые недели после китайского анонса. |
| **Sweet Spot Score** | Оценка рациональности покупки на вторичном рынке в текущий момент. |

## 🏗️ Архитектура

```text
deprecio/
├── core/                  # Математическое ядро, формулы амортизации и регрессии
├── models/                # Схемы данных устройств, рынков и цен (Pydantic)
├── harvester/             # Модули сбора рыночных цен и снапшотов
├── cleaner/               # Фильтрация спама, отсечение битых экранов и выбросов (IQR)
├── forecast/              # Предиктор удешевления на базе исторических данных линейки
└── cli/                   # Консольный интерфейс (Typer + Rich)

data/
└── devices/               # Каталог спецификаций смартфонов (YAML)
```

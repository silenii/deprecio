# 📉 Deprecio (Депрецио)

## 🎯 О проекте

**Deprecio** (от фин. *depreciation* — обесценивание, амортизация) — это аналитический инструмент для энтузиастов и покупателей мобильной техники в России, ориентированный на глубокий анализ вторичного рынка (в первую очередь, площадок объявлений вроде **Авито**):
- **Анализ версионности (Editions):** учет влияния региональной версии смартфона на его ликвидность и цену:
  - *Китайские версии (CN)* — специфика прошивки, отсутствие Band 20, ранний выход на рынок, низкая цена в юанях, но риск резкого падения на вторичке.
  - *Ростест / EAC* — официальная сертификация, гарантия, максимальная остаточная стоимость на рынке РФ.
  - *Глобальные версии (Global / EU)* — европейские вилки, стандартные частоты, компромиссная цена.
  - *Американские версии (US)* — поддержка mmWave, специфика слотов SIM (только eSIM во многих моделях), отсутствие комплектных адаптеров.
  - *Индийские версии (IN)* — локальные особенности конфигураций (часто отсутствие NFC или другие сенсоры камер).
- **Разница в комплектациях:** влияние наличия оригинального зарядного блока, чехла и аксессуаров на итоговую стоимость устройства при перепродаже.
- **Прогнозирование падения цен:** предиктивная модель уценки новинок на основе исторического поведения прошлых поколений тех же линеек.
- **Детекция «Sweet Spot Window»:** расчет оптимального момента для покупки устройства, когда первоначальный обвал цен завершился и стоимость вышла на стабильное плато.

## 📊 Ключевые метрики

| Метрика | Описание |
| :--- | :--- |
| **RV% (Residual Value)** | Процент сохранения остаточной стоимости устройства от стартовой розничной цены. |
| **Edition Price Gap** | Разница в цене между региональными версиями одной и той же модели на вторичном рынке (например, CN vs EAC). |
| **Bundle Value Factor** | Влияние комплектности (полный комплект, коробка, родная быстрая зарядка) на скорость и цену продажи. |
| **Sweet Spot Score** | Оценка рациональности покупки устройства на вторичном рынке в текущий момент. |

## 🏗️ Архитектура

```text
deprecio/
├── core/                  # Математическое ядро, формулы амортизации и предиктивные алгоритмы
├── models/                # Pydantic-схемы устройств, региональных версий и объявлений
├── harvester/             # Модули сбора данных (парсеры площадок объявлений и маркетплейсов)
├── cleaner/               # Фильтрация спама, отсечение битых экранов, дефектов и выбросов (IQR)
├── providers/             # Адаптеры интеграции с базами спецификаций (Nanoreview, Kimovil и др.)
├── forecast/              # Предиктор уценки новинок на базе исторических данных
└── bot/                   # Telegram-бот и интерфейсы взаимодействия

data/
└── devices/               # Каталог спецификаций моделей и конфигураций (YAML)
```
